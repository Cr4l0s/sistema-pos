3. DETALLE TÉCNICO DE SOLUCIONES
--------------------------------------------------------------------------------

3.1. Problema: Exportaciones solo página actual
------------------------------------------------
Solución: Crear dos funciones de URL en tabla_pro.js

function construirUrlVista() {
    // Usa pagina, filas actuales, respeta filtros
}

function construirUrlExportacion() {
    // Usa filas=-1, pagina=1, buscar='', categoria=0
    // sin_acciones=1 para ocultar botones
}

3.2. Problema: Error al ordenar por Moneda/Símbolo
---------------------------------------------------
Solución: Corregir switch de ordenamiento y JOINs

switch ($orden_validado) {
    case 'codMoneda': $campo_orden = 'm.codMoneda'; break;
    case 'simbolo_moneda': $campo_orden = 'm.simbolo'; break;
    // ...
}

3.3. Problema: Paginación no se actualiza al buscar
----------------------------------------------------
Solución: Separar consultas de conteo

// Sin búsqueda: COUNT simple
$sql_total = "SELECT COUNT(*) as total FROM paises p WHERE p.vigente = 1";

// Con búsqueda: COUNT con JOINs
$sql_total = "SELECT COUNT(DISTINCT p.idPais) as total ...";

3.4. Problema: PDF muestra '—' en columna Tienda
-------------------------------------------------
Solución: Convertir íconos a texto en el procesamiento

if (valor.includes('✅')) {
    valor = 'Sí';
} else if (valor.includes('❌')) {
    valor = 'No';
}

3.5. Problema: Mensaje eliminar no muestra nombre
--------------------------------------------------
Solución: Obtener nombre antes de eliminar

$sql_nombre = "SELECT nombrePais FROM paises WHERE idPais = ?";
// ... luego usar en mensaje
$_SESSION['mensaje'] = "País '$nombrePais' eliminado correctamente.";
