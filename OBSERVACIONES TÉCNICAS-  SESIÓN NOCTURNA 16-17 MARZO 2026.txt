2. PROBLEMAS DETECTADOS Y SOLUCIONADOS
--------------------------------------------------------------------------------

2.1. Error "headers already sent" (pais-editar.php línea 8)
     • Síntoma: "Warning: Cannot modify header information - headers already sent"
     • Causa raíz: Salida HTML en menu.php antes de incluir pais-editar.php
     • Solución: Se verificó que menu.php ya tenía ob_start() al inicio, pero se
       identificó que el error era secundario a otros problemas
     • Archivo involucrado: menu.php

2.2. Variable $idPais indefinida (pais-editar.php línea 21)
     • Síntoma: "Warning: Undefined variable $idPais"
     • Causa raíz: La variable se usaba antes de ser inicializada correctamente
     • Solución: Se reorganizó el código para asegurar que $idPais se define
       antes de cualquier uso
     • Archivo modificado: pais-editar.php

2.3. Error de sintaxis $_ids_excluir (pais-editar.php línea 69)
     • Síntoma: "Undefined variable $_ids_excluir" y "implode() argument must be array"
     • Causa raíz: Se escribió $_ids_excluir con guión bajo en lugar de $ids_excluir
     • Solución: Corrección del nombre de variable y verificación de que sea array
     • Archivo modificado: pais-editar.php

2.4. Página en blanco (pais-editar.php)
     • Síntoma: Pantalla completamente blanca sin contenido
     • Causa raíz: Error fatal de PHP no mostrado por configuración del servidor
     • Solución: Activación temporal de display_errors para diagnóstico
     • Archivo modificado: pais-editar.php (temporal)

2.5. Codificación de caracteres (UTF-8)
     • Síntoma: Caracteres mostrados como rombos con interrogación ( ), símbolos
       como "???" en lugar de "ден", "₡", "₫"
     • Causa raíz: La base de datos tenía codificación latin1_swedish_ci pero el
       servidor esperaba UTF-8. Además, la conexión PHP estaba en latin1
     • Solución: 
        - Se verificó y corrigió db.php con $conn->set_charset("utf8mb4")
        - Se agregó header('Content-Type: text/html; charset=utf-8') en todos los archivos
        - Se reemplazó htmlspecialchars por htmlentities para símbolos especiales
        - Se corrigió codificación de tablas problemáticas (categorías, productos)
     • Archivos modificados: db.php, pais-editar.php, pais-crear.php

2.6. Búsqueda de monedas insensible (matcher)
     • Síntoma: Al escribir "dol" no aparecía "Dólar estadounidense"
     • Causa raíz: El matcher no normalizaba acentos (buscaba "dol" vs "dólar")
     • Solución: Se implementó función matcherCustom con normalización Unicode
       (eliminación de acentos mediante normalize("NFD"))
     • Archivos modificados: pais-editar.php, pais-crear.php

2.7. Moneda duplicada/errónea DUP
     • Síntoma: Aparecía "DUP - peso dominicano (KUS)" en lugar de DOP
     • Causa raíz: Registro incorrecto en tabla monedas
     • Solución: Se identificó y se recomendó eliminación del registro DUP e
       inserción correcta de DOP
     • Base de datos: Tabla monedas

2.8. Países duplicados en listado
     • Síntoma: Países aparecían dos veces en el listado (ej: "Afganistán" y "Afganistán, Afghanistan")
     • Causa raíz: Inserciones múltiples de los mismos países
     • Solución: Se proporcionó script para eliminar duplicados y mantener solo
       registros únicos
     • Base de datos: Tabla paises

2.9. Permisos de usuario en base de datos
     • Síntoma: Error #1044 - Acceso denegado al ejecutar ALTER TABLE
     • Causa raíz: Usuario 'practica' sin permisos de modificación de estructura
     • Solución: Se optó por cambios manuales vía phpMyAdmin (interfaz gráfica)
       en lugar de SQL directo
     • Base de datos: Varias tablas

4. MEJORAS IMPLEMENTADAS
--------------------------------------------------------------------------------

4.1. Búsqueda inteligente de monedas
     • Antes: Solo buscaba por texto exacto, sensible a acentos
     • Ahora: Busca por código, nombre y texto, ignorando acentos y mayúsculas
     • Ejemplo: "dol" encuentra "Dólar estadounidense (USD)"

4.2. Visualización de caracteres especiales
     • Antes: Símbolos como "ден", "₫", "C$" se veían como "???"
     • Ahora: Todos los símbolos se muestran correctamente gracias a:
        - header('Content-Type: charset=utf-8')
        - $conn->set_charset("utf8mb4")
        - htmlentities() para escape seguro

4.3. Selectores independientes (país)
     • Antes: Al seleccionar sigla, se autocompletaba nombre (y viceversa)
     • Ahora: Selectores independientes - sigla solo actualiza sigla, nombre solo nombre
     • Beneficio: Libertad total para combinaciones (ej: Chile con sigla XX)

4.4. Estabilidad del código
     • Antes: Errores fatales por variables indefinidas y tipos incorrectos
     • Ahora: Validaciones en todas las variables críticas
     • Ejemplo: Verificación !empty($ids_excluir) antes de implode()

4.5. Diagnóstico
     • Se creó archivo test_encoding.php para verificar charset de conexión
     • Se creó test_pais.php para verificar funcionalidad básica
     • Beneficio: Facilidad para futuras depuraciones
