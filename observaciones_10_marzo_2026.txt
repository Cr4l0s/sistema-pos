2. SISTEMA DE MENSAJES UNIFICADO
   -------------------------------------------------
   Se implementó un sistema estándar para todos los mensajes del sistema:

   ```php
   $_SESSION['mensaje'] = 'Texto del mensaje';
   $_SESSION['tipo_mensaje'] = 'success'; // success, danger, warning, info
Archivo mensaje.php actualizado para mostrar el tipo correcto:

php
<?php 
if(isset($_SESSION['mensaje'])):
    $tipo = $_SESSION['tipo_mensaje'] ?? 'warning';
?>
<div class="alert alert-<?= $tipo ?> alert-dismissible fade show" role="alert">
    <?php echo $_SESSION['mensaje']; ?>
    <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
</div>
<?php
    unset($_SESSION['mensaje']);
    unset($_SESSION['tipo_mensaje']);
    endif;
?>
Colores estandarizados:

🟢 success → Verde (operaciones exitosas)

🔴 danger → Rojo (errores)

🟡 warning → Amarillo (advertencias)

🔵 info → Azul (información neutral)
