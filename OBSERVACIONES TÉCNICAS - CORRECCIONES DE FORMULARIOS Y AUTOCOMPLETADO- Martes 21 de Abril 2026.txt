1.1 ERROR DE SINTaxis EN categoria-editar.php
---------------------------------------------
PROBLEMA: El campo "Nombre de la Categoría" mostraba texto HTML literal:
"value="Accesorios Electrónicos" required> Solo letras, números y espacios"

CAUSA: La línea del input estaba duplicada:
```php
<input ... value="<?= htmlspecialchars(...) ?>" ... required>
       value="<?= htmlspecialchars(...) ?>" required>
SOLUCIÓN: Se eliminó la línea duplicada, dejando solo un input correcto:

php
<input type="text" class="form-control" name="nombre_categoria" id="nombre_categoria" value="<?= htmlspecialchars($categoria['nombre_categoria']) ?>" autocomplete="off" required>
<small class="text-muted">Solo letras, números y espacios</small>
1.2 ERROR EN bind_param DE producto-acciones.php

PROBLEMA: Error "ArgumentCountError" al crear producto.

CAUSA: La cadena de tipos "ssidddiiii" tenía 10 caracteres pero se pasaban 9 variables.

SOLUCIÓN: Se corrigió la cadena a "ssiddiiii" (2s + 1i + 2d + 4i = 9):

php
$stmt->bind_param("ssiddiiii", $codigo_barras, $nombre, $id_categoria, $precio_compras, $precio_venta, $stock_actual, $stock_minimo, $mostrar_en_tienda, $idUsuario);
1.3 ERROR DE FOREIGN KEY EN producto-acciones.php

PROBLEMA: Error "Cannot add or update a child row: a foreign key constraint fails".

CAUSA: $idUsuario no tenía un valor válido.

SOLUCIÓN: Se aseguró que $idUsuario tenga un valor por defecto:

php
$idUsuario = $_SESSION['usuario_id'] ?? 1;
1.4 SUGERENCIAS DEL NAVEGADOR (AUTOCOMPLETADO)

PROBLEMA: El navegador mostraba sugerencias de valores anteriores en los campos de texto.

SOLUCIÓN: Se agregó autocomplete="off" o autocomplete="new-password" en todos los formularios.

3. FUNCIÓN PARA NOMBRE DINÁMICO DE CÓDIGO DE BARRAS
================================================================================

Para evitar sugerencias del navegador en el campo "Código de Barras", se implementó
una función que genera un nombre dinámico para el input:

php
function obtenerCodigoBarras() {
    foreach ($_POST as $key => $value) {
        if (strpos($key, 'codigo_barras_') === 0) {
            return !empty(trim($value)) ? limpiarInput(trim($value)) : null;
        }
    }
    return isset($_POST['codigo_barras']) ? limpiarInput(trim($_POST['codigo_barras'])) : null;
}
