2. FUNCIÓN PARA NOMBRE DINÁMICO DE CÓDIGO DE PRODUCTO
================================================================================

En producto-acciones.php se agregó:

php
function obtenerCodigoProducto() {
    foreach ($_POST as $key => $value) {
        if (strpos($key, 'codigo_producto_') === 0) {
            return !empty(trim($value)) ? limpiarInput(trim($value)) : null;
        }
    }
    return isset($_POST['codigo_producto']) ? limpiarInput(trim($_POST['codigo_producto'])) : null;
}

6. ESTRUCTURA DE DIVS EN producto-ver.php (ACLARACIÓN)
================================================================================

La estructura de Bootstrap utilizada:

<div class="row"> = fila horizontal

<div class="col-md-6"> = columna vertical dentro de la fila

El cierre es LIFO: se cierra primero la columna, luego la fila

Ejemplo:

php
<div class="row">           // 1. ABRE fila
    <div class="col-md-6">  // 2. ABRE columna
        contenido
    </div>                  // 2. CIERRA columna
</div>                      // 1. CIERRA fila
